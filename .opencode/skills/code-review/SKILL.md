description: Review code changes or files for bugs, security, and quality
---

Review the code for bugs, security issues, performance problems, and code quality concerns. Be specific and actionable. Check for:
- Logic errors and edge cases
- Security vulnerabilities (SQL injection, auth bypass, data leakage)
- Performance bottlenecks
- Error handling gaps
- TypeScript/Prisma best practices
- Multi-tenant isolation (schoolId filtering)
